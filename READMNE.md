# SGME — Guía de instalación y conexión

Sistema de Gestión de Matrícula Escolar desarrollado con:

- React + Vite
- Python + Flask
- PostgreSQL

La comunicación del sistema es:

REACT → AXIOS → FLASK → DAO → POSTGRESQL

---

## 1. Programas necesarios

Instalar:

- Git
- Python
- Node.js + npm
- PostgreSQL
- pgAdmin 4

Opcional:

- Visual Studio Code
